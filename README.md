# Поиск по базе знаний через n8n
Учебная цепочка: Python-клиент → n8n Webhook → локальный Python-сервис → ChromaDB и GigaChat → ответ.

## Комплект
- server.py — HTTP-сервис на 127.0.0.1:8796.
- rag_service.py — загрузка и поиск с дополнительным ранжированием.
- provider_adapter.py, config.py, embeddings/ — провайдер, настройки и код векторизации.
- data/ — три вымышленных документа, всего шесть абзацев.
- workflow-upload.json, workflow-search.json — импортируемые сценарии n8n без учётных данных.
- upload_files.py — загрузка комплекта через n8n.
- test_store.py — интеграционная проверка поиска без вызова LLM.
- test_search_api.py — пять запросов через n8n с вызовом GigaChat.
- requirements.txt, .env.example, .gitignore — настройка и исключения.

## Запуск
После подготовки запустите `python server.py`. Импортируйте оба workflow в свой n8n и активируйте их. Они импортируются неактивными.
Для n8n на хосте замените адрес HTTP Request на http://127.0.0.1:8796. В комплекте используется host.docker.internal для Docker Desktop; доступность сервиса через этот адрес зависит от сети Docker и должна проверяться отдельно. Не открывайте незащищённый сервис в интернет.
Выполните `python upload_files.py`, затем `python test_search_api.py`.
Адреса webhook можно задать PER05_UPLOAD_URL и PER05_SEARCH_URL. Проверка хранилища: `python -m unittest -v test_store`.
Генерируемые upload-result.json и search-results.json исключены из Git.

Поиск рассчитан на три приложенных файла, по два абзаца до 600 символов. score и rank_score — показатели ранжирования, не вероятность правильности ответа.
## Подготовка
Python 3.11. Установите зависимости: `python -m pip install -r requirements.txt`.
Скопируйте `.env.example` в `.env` и заполните собственный ключ GigaChat. Можно указать внешний файл переменной RAG_PROVIDER_ENV. Ключи в комплект не входят. TLS-проверка включена; GIGACHAT_CA_BUNDLE позволяет указать свой доверенный набор сертификатов.

Для поиска нужен заранее загруженный кэш модели sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2 для FastEmbed. Укажите каталог через FASTEMBED_CACHE_PATH; по умолчанию используется model-cache в корне проекта. Автоматическая загрузка отключена (local_files_only=True). Модель и векторный индекс не включены.

## Данные и ограничения
Данные сервисного центра вымышлены. Найденные фрагменты и вопросы передаются GigaChat для генерации; в консольном ассистенте передаётся также история диалога. Не используйте личные данные без предварительного обезличивания. Это учебный проект, не промышленный сервис. Модель может ошибаться.

Проверки с моделью требуют локального кэша и доступа к API. Полный запуск очищенной копии на новом компьютере не выполнялся. Старые журналы экспериментов не включены; наличие тестов не означает, что они пройдены в этой копии.
